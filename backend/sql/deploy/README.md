## Step order (changed in Round 4: DEPLOY-ROUND-4.md supersedes DEPLOY-ROUND-3.md)

cannot see rows the running user is not entitled to and would insert duplicates on a re-run (N4-02). Steps 05 and 06
detach the policy first (a no-op on a fresh account); step 07 recreates and re-attaches it.
**If step 05, 06 or 07 fails part way, run step 07 again before anything else.** Steps 08 and 09 refuse to run
(a raised exception, not a silent pass) while `DOC_PAGE` has no `PATIENT_SCOPE` policy.

## Known caveats
* The cohort document `effective_at` values are frozen when the manifest was generated; `load_daycare_cohort.sql`
  re-anchors event dates to the deploy day. If you deploy on a later day, regenerate the manifest first
  (`./venv/bin/python -m data.generator.cohort_documents --manifest data/generated/cohort_document_manifest.json`,
  then rebuild this bundle) or the document to event `supports` links will not match by date.
* A web server that was built earlier must be restarted after step 8.
* Step 08 reads DOC_PAGE through the row access policy, which keys on `CURRENT_USER()` (AGENTS.md 3.1): run it as the
  Snowflake user stored on practitioner `PRAC-01`. Its first statement is a guard that raises when the user, the
  procedures, the policy or the cohort pages are wrong, so a mismatch fails loudly instead of seeing nothing.
* `RELEASE_PATIENT_BINDING`, `ASK_SAARTHI`, `CHUNK_DOCUMENTS_PROC`, `EXTRACT_ASSERTIONS_PROC`
  and `REFRESH_READINESS_PROC` are NOT created by this bundle; step 00 lists any that are missing (deploy them from the repo).
* `SAARTHI_AGENT` and `SAARTHI_MCP` are not created by the bundle; their grants are guarded and report `skipped` if absent.
* The canary document `DOC-RAP-CANARY-01` (patient `PAT-RAP-CANARY`, no care team) is synthetic test data kept for the
  negative test; it is excluded from the verification counts by name.
* PAT-DEEP-0001 can show a document-cited gate span only after the two-pass run verifies an assertion from
  DOC-SURG-NOTE-01 (or the live Tata Memorial CBC); that is intended and is not forced by the seed.
