# Failure-and-fix index

AGENTS.md section 4: record failures, do not curate them out. This is an index into where they are recorded. It does
not replace the source files; follow the links for the full reasoning.

**Verification status vocabulary** (used in the last column):

- **verified live** - a Snowflake query or run on a named account confirmed the fix. *Reported*, not re-runnable
  offline; IDs are in the linked evidence.
- **verified offline** - re-runnable without Snowflake (unit, contract, e2e or generator tests). Engineering check on
  synthetic data, not clinical validation.
- **unverified-needs-deploy** - changed in source, offline tests pass, never executed on Snowflake. Every `backend/sql`
  change from QA rounds 1 to 4 is in this state until the [deploy bundle](../backend/sql/deploy/README.md) is run.
- **open** - not fixed, or a decision is pending.
