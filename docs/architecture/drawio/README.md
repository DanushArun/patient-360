## How this file is produced

Generated by `tools/drawio/`, not hand-drawn:

```bash
python3 -m tools.drawio.generate
```

| Module | Responsibility |
|---|---|
| `model.py` | the shared palette, element dataclasses, grid layout, boundary geometry |
| `serialize.py` | mxGraph/XML emission and per-page id namespacing |
| `validate.py` | structural and geometric validation |
| `pages_c4.py` | pages 1–5 |
| `pages_flow.py` | pages 6, 7, 8, 11, 14, 15 |
| `pages_data.py` | pages 9, 10, 12, 13 |
| `generate.py` | assembles, validates, writes — refuses to write if validation fails |

**Why generated.** Fifteen diagrams laid out by hand drift: the same concept ends up a different colour on page 3 than on page 11, and boxes creep out of alignment. Defining them in one place makes the palette and geometry provably consistent, and the whole set regenerates in under a second when the architecture changes.

**Validation runs before the file is written and blocks on failure.** It checks:

- XML well-formedness and globally unique cell ids
- every edge endpoint resolves to a cell that exists **on the same page**
- **no two elements overlap** — boundaries excluded, since they are meant to contain
- **label text fits its box**, honouring explicit line breaks and estimating wrap

That last two are the checks that matter. They catch exactly the defect that is invisible in XML and fatal on screen — and they are why the first generated draft was rejected for a note box 40px too short.

## ⚠️ If you edit by hand

Once you edit this file in draw.io, **the `.drawio` file becomes the source of truth and regenerating will overwrite your edits.** Either keep edits out of the generator's way by exporting to a new filename, or fold the change back into the relevant `pages_*.py` and regenerate.

## Exporting

Nothing is committed but the source. To export images:

```bash
# in the draw.io app:  File → Export as → PNG / SVG / PDF
# or with the desktop CLI:
drawio -x -f png -s 2 --all-pages SAARTHI-architecture.drawio
```

Use **SVG for the deck** — it stays sharp when projected. Page 6 is the one to have on screen when a judge asks how scope is enforced.
